Тестовое задание

Необходимо реализовать сервис отправки сетевых сообщений
(NetworkMessages) между сервером и клиентом с использованием плагина Mirror.

В плагине уже реализован механизм обмена сетевыми сообщениями,
однако он имеет ограничение: сервер отключает клиента, если клиент не
зарегистрировал обработчик для конкретного типа сообщения. Требуется
разработать собственное решение, не модифицируя исходный код плагина, на
основе стандартных сетевых сообщений Mirror, которое позволит отправлять
сообщения только тем клиентам, которые явно подписались на
соответствующий тип сообщения.

Сценарий работы должен быть следующим:
1. Запускается сервер (или хост);
2. Подключается клиент;
3. Клиент подписывается на получение сообщения типа HelloMessage;
4. Сервер получает информацию о подписке клиента;
5. Сервер отправляет клиенту сообщение HelloMessage с текстом "Hello Client!";
6. Клиент принимает сообщение и выводит текст в консоль.

Технические требования:
1. Версия Unity: 2022.3.62f3;
2. Реализованный сервис должен быть зарегистрирован в DI-контейнере: Zenject или VContainer;
3 Необходимо предоставить ссылку на репозиторий Git с результатом выполнения задания.
